# <u> **Curve Fitting and Parameter Estimation based on Planck's Experiment data** 
The goal of this assignment is to esttimate the parameters in the Planck's equation for black body radiation using the  four data samples provided in the Curve Fitting/data folder. 

Planck's equation for black-body radiation provides a relation between the **spectral radiance per unit wavelength** and the corresponding **wavelength** of the radiation:

$$
B(\lambda, T) = \frac{2 h c^2}{\lambda^5} \cdot \frac{1}{e^{\frac{h c}{\lambda k_B T}} - 1}
$$

Where:

- $$B(\lambda, T) $$= Spectral radiance per unit wavelength  
- $$\lambda$$ = Wavelength of the radiation  
- T = Temperature of the black-body  
- h = Planck's constant  
- c = Speed of light  
- $$k_B$$= Boltzmann constant  

This equation shows how the emitted radiation of a black-body depends on its temperature and the wavelength of observation.
