# <u>**Sound-Localization**
## **Objective**
The goal of this assignment is to develop the Python code for image reconstruction using the Delay and Sum  (DAS) algorithm commonly used in Ultrasound Image Reconstruction.

It is also required to apply the code to new datasets to reconstruct the iamges to identify the location of the obstacles.

**Input Data-**
- There are two text files containing samples corresponding to two locations of obstacles.
- It should beable to load them using the numpy.loadtxt function - they are  matrices corresponding to 64 mics and 200 samples per mic.
- Reconstruct the images from these and interpret your results.
